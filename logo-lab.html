C · wordmark only

Pure wordmark — no illustrated mark

No mark at all. Oversized italic "N2G" as the anchor, with "NativeToGlobal" set below as a small-caps sans-serif subtitle. This is the most editorial option — closest to Cereal, Kinfolk, or Drift aesthetics. Lives or dies on typography alone, which is exactly the point. Also the cheapest to execute because there's nothing to design.

Tell me which letter (A, B, C, or D) you prefer and I'll apply it to the nav + footer on the main site in one pass. If none of them feel right, tell me which direction is closest and I'll iterate.

Notes
  • All four treatments use the site's existing type stack and colors — no new fonts or assets to load.
  • Treatment C is the cheapest to execute and the most editorial. Treatment B is the most brand-forward of the mark-based options.
  • Whatever you pick here is still a CSS placeholder. For launch, you should commission a real logo from a designer. These treatments can be handed to them as directional reference ("we're going in this direction").
  • This page is noindex, nofollow, and not linked from the main nav — it won't appear in search results or accidental navigation.
