Logo lab

Eight treatments to compare — four CSS-only (A–D) and four refined SVGs (E–H). All use the existing type stack (EB Garamond + Karla) and color palette. E–G evolve the editorial directions of B, C, and D; H refines A with a serif italic monogram upgrade. SVG treatments offer precise geometry, multi-scale icon variants, and packaging-ready exports.

C · wordmark only

Pure wordmark — no illustrated mark

No mark at all. Oversized italic "N2G" as the anchor, with "Native2Global" set below as a small-caps sans-serif subtitle. This is the most editorial option — closest to Cereal, Kinfolk, or Drift aesthetics. Lives or dies on typography alone, which is exactly the point. Also the cheapest to execute because there's nothing to design.

E · double ring · SVG

Double-ring mark + serif wordmark

Evolves Treatment B into a precise SVG. A thin outer ring and subtle inner ring create a wax-seal quality-stamp feel. How to use this page
Preview at https://native2global.com/logo-lab.html once the domain is live, or at https://n2g-site.vercel.app/logo-lab.html right now. Tell me which letter (A through H) you prefer and I'll apply it to the nav + footer on the main site in one pass. If none of them feel right, tell me which direction is closest and I'll iterate.

Notes
  • All four treatments use the site's existing type stack and colors — no new fonts or assets to load.
  • Treatment C is the cheapest to execute and the most editorial. Treatment B is the most brand-forward of the mark-based options.
  • Treatments A–D are CSS placeholders. E–H are inline SVGs that can be extracted for packaging, print, or handed to a designer as production-ready starting points.
  • E–H use <symbol>/<use> for deduplication. Each SVG references the page's Google Fonts — the same EB Garamond + Karla loaded by the site.
  • This page is noindex, nofollow, and not linked from the main nav — it won't appear in search results or accidental navigation.
